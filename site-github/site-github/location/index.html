Frais pour le locataire

Plafonnés par la loi

À Bordeaux (zone tendue) : 10,09 € par m² pour la visite, le dossier et le bail, et 3,03 € par m² pour l'état des lieux. Le dossier est gratuit.

Exemple : un T2 de 45 m² = 590,40 € TTC au maximum.
